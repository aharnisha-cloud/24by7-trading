# logs/ — Decisions and results

Every decision gets logged, including rejections. This is the record you'll
review later to see what's actually working.

- `decisions.md` — one row per proposal (approved or not)
- `results.md` — one row per closed paper trade

Periodically ask the AI to review these files: win rate, average reward:risk,
which setups/criteria performed best, and what to change.
